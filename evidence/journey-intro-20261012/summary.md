## 覆盖

- 阶段来源为真实计划状态，不按模型措辞或时间推断结束；确认弹窗与引导不叠加。
- 首次介绍、两个阶段切换、跳过不触发写入、查看旧阶段不倒退业务状态。
- 刷新不重复，账号隔离，退出清除当前展示，存储不可用容错；直接工具链接不先被引导拦住。
- Escape、Tab、关闭后焦点回到入口；当前阶段而非第一张卡牌获得初始焦点。
- 预览手动重播零 API 请求、零已看记录写入；普通业务回归按已看过引导的账号运行，引导首访由独立测试覆盖。
- 减少动态效果时粒子及卡牌动画均关闭；透明外层样式有断言。
