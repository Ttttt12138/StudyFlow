# StudyFlow 当前演示流程（2026-10-15）

本页与[前后端统一说明](student-loan-contract.md)同步。所有贷款、录取通知、余额和支付均为模拟。

## 登录后的完整链路

1. 对话查询学校全程总价，比较学校，选择学校和学制。
2. 打开「我的方案」，直接填写需要贷款的金额。不输入可用资金，不计算资金缺口，也没有「无需贷款」确认选项。
3. 选择产品、期限和还款方式，点击「估算还款」。核对本金、利息、手续费、月供和总还款；修改金额后必须重新估算。
4. 点击「确认方案并提交申请」，核对确认页后提交。申请自动附加模拟录取通知；审批检查金额不超过全程费用，手续费不增加贷款上限。
5. 「待办与账单」「钱包与支付」此时开放。未提交申请时，对话中的钱包、换汇和汇款请求会提示先提交贷款申请。
6. 将其余材料标记完成后明确确认签约。录取通知已自动完成，不能手工取消；没有确认入学步骤。
7. 签约生成按学期付给学校的计划及真实的模拟贷款账户。查看贷款未覆盖的学校账单，必要时使用模拟钱包支付。
8. 在「待办与账单」推进演示日期至还款日，回「我的方案」确认还款并按策略完成密码验证。检查本期已还、余额及流水。

实际端到端回归见 `frontend/tests/e2e/integration/plan.spec.mjs`。该用例使用真实 Django/PostgreSQL 接口、隔离账号和规则规划器，覆盖自动通知、签约、学校付款计划与还款；不需要重置开发数据库。

## 无需后端的只读预览

打开 `/?tour=1` 运行 8 站导览：查价、比价、贷款估算、申请与材料、待办与账单、钱包、付款、还款流程说明。导览分为 `plan`（咨询）和 `prepare`（已提交申请）两阶段。`stage=school` 旧链接兼容映射到 `prepare`。

- 咨询与贷款估算：`/?plan=preview&tool=funding`
- 已申请与自动通知：`/?plan=preview&stage=prepare&tool=funding`
- 待办与账单：`/?plan=preview&stage=prepare&tool=life`
- 钱包与支付：`/?plan=preview&stage=prepare&tool=wallet`

预览禁止写入，不会签约或还款；末站解释还款步骤。中英文录制数据均由统一 API 录制器重新生成。
