## Gemini OCR 未完成项

实际尝试 `verify_document_ocr --live`，在外发前被现有部署策略检查拒绝：`OCR deployment policy gates are not configured`。当前 OCR 关闭，付费服务／成年用户部署确认未设置，模型名为空；密钥存在但没有输出或写入报告。

因此未发生真实 OCR 调用，不能报告识别成功率。现有 Gemini 引擎、人工转录、显式重试和失败复核已接通；真实验收还需要模型配置及 [现有 OCR 部署要求](gemini-ocr.md) 的确认。这不是自动审批拒绝，也没有自动切换其他引擎或 mock 来冒充验收。

## 重现

使用 [接入文档](copilot.md) 中的启动、Demo 和评估命令。PostgreSQL 必须运行；模型凭据由现有环境配置读取。每轮 Demo 新建独立合成身份及报告。测试报告位于被 Git 忽略的 `output/`，交付时应连同所需证据一起保留；仓库内摘要保留报告哈希和指标，便于核对。

机器可读归档：[验收摘要及 SHA256](copilot-verification-summary.json)。其中同时记录首次冻结测试失败、最终回归通过和真实 OCR 未调用，不合并为“全部正式验收已通过”。
