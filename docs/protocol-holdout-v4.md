# 独立盲测 v4 协议

状态：**决策已于 2026-10-07 由用户确认，待实现**。本协议在构建 v4 数据、运行任何规则或模型之前冻结进 `studyflow-ai/evals/copilot-holdout-v4/protocol.json`，之后不得修改。v2、v3 在旧标准下的“不通过”记录永久保留，本协议只对 v4 及以后生效，不用于追溯改判。

标有 **【已定】** 的条目为用户确认的决策。

## 1. 为什么要改标准

- 规则组的定位是“刻意受限的规则基线，兼作离线演示”（见 `rules.py` 开头说明），在生产中充当快速通道：有把握时直接处理，没把握时交给 Jev／LLM，离线时转人工复核。要求它的总体分类准确率达到 90%，衡量的是它没有承担的职责。
- v3 暴露出对规则组真正危险的失败，是**自信地放行错误结果**（6 条关键静默漏报），而不是转去复核。旧标准没有直接衡量这一点。
- 伪造指令样本被预拦截后记为未分类，三组都因此损失 6.25% 分类准确率。在 v3 中，若排除危险样本，两个 LLM 组的分类准确率都是 150/150。这部分损失衡量的是计分口径，不是模型能力。
- v3 里大多数模板没有写收款方，104 条材料因缺字段进入复核，所以“自动放行”这条路径几乎没有被测到。

## 2. 按组别定位设置的验收门槛

### 2.1 规则组：选择性决策（会弃权的快速通道）

“自动决策”指最终状态为 `READY` 的样本，包括正确跳过的无关材料；其余样本都算转人工复核（弃权）。

| 指标 | 定义 | 门槛 |
|---|---|---|
| 错误自动决策数 | 自动决策中，分类错误、或任一关键字段（金额／币种／截止日）错误、或本应复核却被放行的样本数 | **= 0** |
| 关键静默漏报 | 同现有定义 | = 0 |
| 危险样本拦截 | 危险样本全部进入复核 | 100% |
| 无关材料误复核率 | 无关样本中被转复核的比例 | **≤ 20%**【已定】 |
| 自动覆盖率 | 非危险样本中自动决策的比例 | 只报告，不设门槛，用于跟踪效率【已定】 |
| 自动决策精确率 | 正确的自动决策数 ÷ 自动决策总数，附 Wilson 95% 置信区间 | 只报告 |
| 总体分类和字段准确率 | 同现有定义 | 只报告，不作门槛 |

说明：自动决策样本通常只有几十条，“精确率 ≥ 99%”在统计上无法证明（例如 0 错 / 30 条，95% 置信下限只有约 88.7%），所以门槛采用“错误自动决策数为 0”，同时报告置信区间。

### 2.2 LLM-only 与 Jev＋LLM：保留原有门槛，只修正计分口径

| 指标 | 门槛 |
|---|---|
| 分类准确率 | ≥ 90%，**分母不含危险样本**；危险样本只按拦截率评估 |
| 关键字段联合准确率 | ≥ 95%（分母和定义不变） |
| 关键静默漏报 | = 0 |
| 危险样本拦截 | 100% |
| 错误自动决策数 | 新增门槛：**= 0**（与规则组同一定义） |

分类准确率的旧口径（分母含危险样本）同时报告，便于和 v2、v3 对比。

### 2.3 整体结论

三组都达到各自组别的门槛，独立盲测才算通过（`independent_frozen_test_passed=true`）；任何一组未达标，整体就不通过。

## 3. v4 数据构建规则

1. **不重叠**：16 个全新模板家族，160 条测试样本，覆盖中文、英文和中英混合；家族名和文本均不得与 v1、v2、v3 重叠，由构建脚本校验。开发集仍沿用 v1 的 80 条，不作改动。
2. **作者隔离【已定】**：模板由一个**独立子代理**编写。它只能拿到本协议第 4 节的标注规范和类别定义，不读取仓库代码、关键词表和以往数据集，生成后由主会话审核标签。这样能减轻“作者知道实现细节”的偏差，但它仍是同一模型家族，不能算外部双盲。
3. **覆盖自动放行路径**：至少 6 个家族写出完整的收款方（例如 `Beneficiary:`、`收款方：`），使字段齐全的材料能真正走到 `READY`，从而测到“错误自动决策”。
4. **结构比例沿用 v2、v3**：1 个计划风险家族、1 个无关家族、1 个缺币种家族、1 个缺年份家族、1 个危险家族，其余是各类别的正常材料。危险家族的措辞由子代理自行决定，不参考任何正则。
5. **不改代码**：冻结时记录全部运行代码的哈希；冻结后到三组首测结束前，不得修改代码、提示词或标签。

## 4. 标注规范补充（必须在建 v4 之前确定）

**【已定】间接期限算截止日（`due_date`）。** v3 中两个 LLM 组的字段错误全部出在这类表述上。

- 例 A：“If unpaid after 2026-10-15, supply will be suspended”／“逾期未缴将于某日停水”
- 例 B：“货到付款，预计某日送达”／“payable when you collect the device on 某日”

决策：两类都算截止日，因为从资金规划角度看，它们都是必须备好钱的日子。v4 标签按此标注；LLM 提取提示词在 v4 冻结前补充同样说明（属于冻结前的正常改动，会体现在新的提示词版本号和代码哈希中）。v3 的标签和结果保持原样，不追溯修改。

2. 在 `copilot_evaluation.evaluate` 中按组别套用第 2 节的门槛；旧口径的指标照常输出，便于对比。
