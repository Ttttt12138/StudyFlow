# Historical design notes

These files come from the first days of the project (2026-10-04). They are kept to show how the design evolved. They do **not** describe the current system and say nothing about proposition C (multi-currency wallets, remittance, FX, tiered permissions, the agent or credit building).

| File | What it is |
|---|---|
| `04_StudyFlow_Backend_Flow_Design.txt` | Proposed backend flow design. The file itself says it is "an implementation proposal, not a description of existing code". |
| `05_StudyFlow_ERD_Design.txt` | Proposed logical data model, written before any migration existed |
| `07_API_Readiness_Audit.txt` | Gap audit of an even earlier backend workspace. Its "not ready" verdict predates the Django backend. |
| `08_Backend_Completion_Report.txt` | Completion report for the first Django/PostgreSQL MVP |

For the current system, see the top-level `README.md`, `openapi.yaml` and the documents in `docs/`.
